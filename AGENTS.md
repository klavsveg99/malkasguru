# Project Rules

## Typography

- **Never use em dashes (—, U+2014) or en dashes (–, U+2013).** Always use the standard keyboard hyphen-minus (`-`, U+002D) instead. This applies to:
  - All copy/text content
  - Titles, meta descriptions
  - Code comments
  - JSON values
  - CSS content properties
  - Anywhere a dash appears in user-facing content
- Standard hyphens in ranges, separators, and pauses: `8:00 - 17:00`, `24-48 stundu laikā`, `Par mums - Kontakti`
